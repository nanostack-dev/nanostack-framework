# Nanostack DB

Type-safe SQL for Go: a statement builder that the compiler checks, and models and table
types generated from your database. It supports PostgreSQL, CockroachDB, MySQL, MariaDB
and SQLite.

```go
stmt := SELECT(RunnerJobs.AllColumns).
	FROM(RunnerJobs).
	WHERE(RunnerJobs.ID.EQ(UUID(jobID)).AND(RunnerJobs.Status.EQ(String("queued"))))

job, err := query.One[model.RunnerJobs](ctx, db, stmt) // (functional.Option[model.RunnerJobs], error)
```

## Origin: a fork of go-jet

Nanostack DB is a fork of [go-jet](https://github.com/go-jet/jet) by Goran Bjelanovic and
its contributors. We adapted it for the Nanostack framework. go-jet's design is the reason we
chose it: every column, literal and expression has a Go type, so comparing a text column with
an integer, or a timestamp with a string, does not compile.

What Nanostack changed:

- **Name and module path.** The library is the `db` module of `nanostack-framework`
  (`github.com/nanostack-dev/nanostack-framework/db`). Package layout and APIs stay as close
  to go-jet as possible, so upstream fixes can still be merged.
- **Native `functional` support.** Generated models can use `functional.Option[T]` for
  nullable columns. Scanning, `MODEL`, `SET` and literals understand `Option`. Query helpers
  return `(Option[T], error)` for zero-or-one rows.
- **Tests.** The integration suites run on testcontainers for every supported database, with
  no Makefile or docker-compose step: fetch the pinned test data once, then one `go test`
  (see [tests/Readme.md](tests/Readme.md)). CockroachDB and MariaDB runs are compiled against
  the models generated from those databases.
- **Identity.** `jet -version` reports Nanostack DB and the go-jet commit it forks. Generated
  files keep go-jet's `Code generated by go-jet` header.

## Using `functional.Option`

**Generate** Option models: `jet -nullable=option ...` (the CLI default stays `pointer`, as in
go-jet), or `template.DefaultWith(postgres.Dialect, template.NullableOption)` in a generator
program. A nullable column becomes `functional.Option[T]`; NOT NULL columns are unchanged.

**Read.** qrm fills an `Option[T]` field exactly like a `*T` field, with the same conversions
on every driver: NULL is `None`, a value is `Some`. A nested `Option[Struct]` (a LEFT JOIN, with
`alias:"x.*"`) behaves like `*Struct`. `*Option[T]`, `Option[*T]`, nested Options, `Option[[]S]` and
`[]Option[T]` panic with the fix in the message.

**Write.** An Option argument is unwrapped wherever it appears: `MODEL`, `MODELS`, `VALUES`,
`SET`, `Literal`, `Raw` arguments and `DebugSql`. `None` writes `NULL` (never `DEFAULT`), like
a nil pointer. A `*functional.Option[T]` argument or `MODEL` field panics, as it does when
reading. Typed literals take an Option: `StringOpt(o)`, `Int32Opt(o)`, `TimestampzOpt(o)`,
`UUIDOpt(o)`... An absent one keeps the plain constructor's cast: on PostgreSQL most are typed
NULLs (`$1::text`), but `IntOpt` and `FloatOpt` are untyped, like `Int` and `Float`; use
`Int64Opt` or `DoubleOpt` where the server must infer the type. SQLite's `DateOpt`, `TimeOpt`
and `DateTimeOpt` format the time in UTC, the instant SQLite's date functions give for a
stored time.

**Query helpers** (`db/query`): `One`/`OneMap` return `(functional.Option[T], error)`,
`All`/`AllMap` return a never-nil `functional.Seq[T]`, plus `Exec` and `Count`.
`sql.ErrNoRows` is never returned. They take the executor explicitly (`*sql.DB`, `*sql.Tx`...).

**Optional filters** (`db/filter`): `When(opt, cond)`, `If(ok, cond)`, `All(...)` and `Any(...)`
drop absent conditions. Do not compare a column with an `XxxOpt` literal: `col = NULL` is
never true.

```go
stmt := SELECT(Invoice.AllColumns).FROM(Invoice).WHERE(filter.All(
	Invoice.TenantID.EQ(UUID(tenant)),
	filter.When(status, func(s string) BoolExpression { return Invoice.Status.EQ(String(s)) }),
))
invoices, err := query.All[model.Invoice](ctx, db, stmt)
```

**Search contract** (`db/search`): the types that every layer of a search shares (`Result`,
`Pagination`, `Sort`, `Cursor`), the page rule `CheckPage`, the limits, the errors and `All`.
It imports the standard library only, so an API or domain package can import it with no SQL
dialect. A client error (`IsClientError`) answers HTTP 400; `ErrUnscoped`, a search with no
tenant scope, is a programming error and answers 500.

```go
if err := search.CheckPage(page); err != nil { // ErrInvalidLimit, ErrInvalidOffset, ErrInvalidCursor...
	return search.Result[Invoice]{}, err
}
```

**Keyset pager** (`db/keyset`): the one keyset pager (ADR 0001). A `Key` reads one ordering
column from a row; `OrderOf` builds a total order (the requested sorts, then a unique
tiebreak) and refuses an unknown sort with `search.ErrUnknownSort`. `Page` and `PageOf` count
the matches and read one page through `db/query`, with the executor as a parameter: they never
read a transaction from a context. `RequireWhere` refuses a page with no `WHERE`
(`search.ErrUnscoped`). The pager supports PostgreSQL; a MySQL or SQLite table is `ErrDialect`.

```go
order, err := keyset.OrderOf(page.Sort, map[SortField]keyset.Key[model.Invoice]{
	SortCreatedAt: keyset.TimeKey(Invoice.CreatedAt, func(m model.Invoice) time.Time { return m.CreatedAt }),
}, keyset.StringKey(Invoice.ID, func(m model.Invoice) string { return m.ID }))
if err != nil {
	return search.Result[model.Invoice]{}, err // ErrUnknownSort
}
return keyset.Page(db, func(m model.Invoice) model.Invoice { return m }, Invoice.AllColumns).
	From(Invoice).
	Where(Invoice.TenantID.EQ(UUID(tenant))).
	RequireWhere().
	Keyset(order).
	Run(ctx, page.Pagination)
```

**Search runtime** (`db/searchexec`): the runtime of the searches that `nano gen repo` writes.
`Contains(term, exprs...)` is the substring rule of every search: it trims the term, makes
`%`, `_` and `!` literal, and matches without case (`ILIKE` on PostgreSQL, `LOWER() LIKE
LOWER()` on MySQL and SQLite). A blank term gives `TRUE`. Matching follows the column's
collation: SQLite folds the case of ASCII letters only (load the ICU extension for Unicode),
and the accent-insensitive collations of MySQL and MariaDB also ignore accents.

```go
stmt := SELECT(Invoice.AllColumns).FROM(Invoice).WHERE(
	Invoice.TenantID.EQ(UUID(tenant)).AND(searchexec.Contains(term, Invoice.Number, Invoice.Customer)),
)
```
