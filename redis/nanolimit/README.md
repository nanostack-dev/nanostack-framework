# redis/nanolimit

The nano module for distributed limits in Redis, shared by every replica: a sliding-window **rate limiter** and a **permit-expirable semaphore**. Both are ports of Redisson's `RRateLimiter` and `RPermitExpirableSemaphore` with their Lua scripts unchanged ([doc.go](doc.go) lists the upstream commit and every change; [NOTICE](NOTICE) and [LICENSE](LICENSE) carry the Apache 2.0 attribution).

- **Provides:** `*Limits` from `NewFromStore(nanocache.Store, *slog.Logger)`: list `Module` after `nanocache.Module`. `New(*redis.Client, *slog.Logger, ...Option)` builds one over a client the service owns, with options `WithFailurePolicy`, `WithClientID`, `WithWarnInterval`.
- **Use:** `limits.RateLimiter(name)` and `limits.Semaphore(name)` return the `RateLimiter` and `Semaphore` interfaces. The name is the Redis key; the caller owns the namespace. Getting one is free: the state is in Redis.
- **Rate limiter:** `TrySetRate`/`SetRate`/`UpdateRate` with `RateConfig{Type: Overall|PerClient, Rate, Interval, KeepAlive, KeepState}`, then `TryAcquire`, `TryAcquireWait`, `Acquire`, `Release`, `AvailablePermits`, `Config`. A limiter per user sets `KeepAlive` (at least `Interval`), so its keys expire after the last use; the next acquire then returns `ErrNotInitialized`, and the caller sets the rate again (example in [doc.go](doc.go)).
- **Semaphore:** `TrySetPermits`/`SetPermits`/`AddPermits`, then `TryAcquire(ctx, lease)` returns a permit ID that `Release` takes. A permit with a lease comes back by itself when the lease ends, so a crashed holder frees it; `NoExpiry` (or a lease <= 0) never expires. Waiting acquires subscribe to the semaphore's release channel. A semaphore per user calls `Expire` after an acquire, with a TTL at least the lease, so the count and the permits leave Redis together.
- **Without Redis** (nil client, no-op cache store, server down): every Redis call returns `ErrUnavailable`. With `FailOpen` (default) an acquire admits: the rate limiter returns `true`, the semaphore returns stand-in permits (`IsStandIn`) whose release is a no-op, and one warning per minute is logged. `FailClosed` returns the error. Reads and configuration calls always return the error. A call whose context ended returns the context's error, never a fail-open admit.
- **Lifecycle:** none: the cache store owns the client.

Run the tests: `go test ./redis/nanolimit/` (no server: failure policy, arguments) and `go test -tags=integration ./redis/nanolimit/` (Docker or `REDIS_TEST_ADDR`): the ported Redisson suites (`*_redisson_*`) and our own (concurrent clients, key TTLs, lease reclaim, deadlines).
